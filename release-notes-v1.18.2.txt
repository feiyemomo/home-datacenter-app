v1.18.2 (build 222) 发布说明

1. 【视觉系统彻底去油腻与流体重构】
   - 彻底移除背景中的水印 Logo 阴影，窗口背景与对话框背景统一对齐微晶原色基底；
   - 摄像头直播与详情页全面重构为 Jetpack Compose 微晶拟态架构，彻底淘汰老旧 XML 凸起质感按钮（3D金属描边与高饱和蓝开关）；
   - 大幅降低直播页与操作栏的蓝色占比，5合1操作栏（重载/拾音/对讲/回放/告警）与云台控制盘使用自然次级微晶胶囊配合当前主题专属流体强调色（琥珀金/电光蓝/薄荷青）；
   - 全面根治录像回放页下层 Activity 穿帮问题（全屏对话框与根容器均注入不透明基底与专属微晶流体背景）。

2. 【OTA 安装包完整性与双重哈希校验】
   - 后端 Release API 新增 SHA-256 实时哈希计算与缓存返回；
   - Android 客户端新增 ApkInstaller.verifyApkIntegrity 校验机制，在下载和安装前执行文件大小、SHA-256 哈希值比对及 Android PackageArchive 签名完整性检测，校验未通过严禁发起安装。

3. 【交互体验与主题联动修复】
   - 修复设置页切换主题时因事件回放导致误跳录像回放页的缺陷；
   - 4 套微晶流体配色（晨曦浅色/曜夜深色/北欧苍翠/日落琥珀）支持全 App 毫秒级即时平滑色彩过渡，无页面重构与视觉跳变。
